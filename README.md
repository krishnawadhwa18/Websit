# Websit

## How to run

This is a static HTML/CSS/JS prototype. You can open it directly or run a simple local server.

### Option 1: Open directly

Open `index.html` in your browser.

### Option 2: Run a local server

From the repo root:

```bash
python -m http.server 8000
```

Then visit:

```
http://localhost:8000
```
